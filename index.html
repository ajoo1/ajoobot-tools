Table → Expression
Available symbols: AND = . or * or & or just placing letters next to each other like AB — OR = + or | — NOT = ' after the letter or ! before it — XOR = ^. Each variable must be a single letter (A, B, C...).
Click any Output value to cycle through 0, 1, and X.

Binary System

Binary arithmetic/logic with a full flag register, plus shift and rotate operations

Binary Calculator
Shift / Rotate
The flag register (CF, ZF, SF, OF, PF) shows automatically after every operation, just like a real CPU.
OF is only meaningful for a shift/rotate count of exactly 1 — for any other count it's shown as undefined, exactly like on real 8086 hardware.

Machine Code (Intel 8086)

Pick an instruction and its operands, and see the exact machine code bytes with a bit-level breakdown

This tool covers the most commonly taught 8086 instructions (MOV, ALU ops, INC/DEC, PUSH/POP, INT, JMP short, and flag instructions) with register-direct and immediate addressing — not a full assembler with label resolution or memory operands.
